# OfferPilot PRD

## 产品定位

OfferPilot 是面向 Java 求职者的 AI 面试训练与求职管理平台，覆盖题库训练、知识问答、模拟面试、简历整理、投递管理、复习、社区和后台治理。

本次迁移以 Spring AI 为统一方向，允许同步调整 API、表结构和迁移脚本；历史运行数据不要求完全兼容，只保留必要配置与核心业务数据。

## 目标

- 从通用后台升级为 AI 求职训练工作台。
- 让 Spring AI 成为默认 AI 运行方式，能用就用。
- 借迁移完成重构，清理旧入口和旧命名。
- 收敛配置，只保留必要项。

## 主要用户

- Java 求职者
- 面试准备中的用户
- 简历和投递管理用户
- 社区用户
- 管理员

## 核心场景

- Dashboard 呈现今天最重要的训练动作。
- Chat 提供流式问答、引用、附件和会话管理。
- Agent 工作台承载 run、审批、工具调用和结果产物。
- Interview、Resume、Applications、Knowledge、Question、Wrong、Review、Analytics 构成主业务链路。
- Admin 处理用户、内容、AI 日志、运行治理和系统配置。

## 范围原则

- 允许重构 API 和表结构。
- 允许补迁移脚本。
- 不要求历史运行数据完全兼容。
- 不保留已退役的旧方案入口。

## 成功标准

- 用户能快速理解今天该做什么。
- AI 页面更像工作台而不是通用表格页。
- 文档只剩当前方案，不再并列旧版本。
