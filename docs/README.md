## 维护规则

- `docs/` 根目录仅保留这 7 份文档。
- 新内容优先更新现有文件，不再恢复旧文件名。
- 产品范围变化更新 `prd.md`，架构变化更新 `tech-design.md`，接口变化更新 `api-spec.md`，表结构变化更新 `database-design.md`，页面体验变化更新 `ux-spec.md`。
